Política de Privacidade — ZAIROX

Desenvolvedor: ZAIROX · Última atualização: 09 de outubro de 2026 · App: com.meujogo.floresta2d

Resumo

O ZAIROX é um jogo de plataforma 2D. Não pedimos cadastro, não coletamos dados pessoais e não vendemos nem compartilhamos informações. O progresso fica salvo apenas no seu aparelho.

1. Dados guardados no seu aparelho

  • Progresso do jogo (fase, moedas, gemas, itens, melhorias, personagens), configurações de som e, quando houver, a ativação da licença.
  • Esses dados ficam no armazenamento local do app (localStorage/IndexedDB) e não são enviados para nós.
  • Desinstalar o app ou limpar os dados dele apaga tudo de forma definitiva.

2. Conexão com a internet

  • O jogo funciona offline. Com internet, ele só baixa atualizações do próprio jogo (arquivos publicados no GitHub Pages).
  • Nesse download, o servidor do GitHub recebe dados técnicos padrão de qualquer acesso à web (como endereço IP e tipo de navegador), tratados conforme a Declaração de Privacidade do GitHub. Nós não recebemos nem guardamos esses dados.

3. Compras

  • Os itens da loja do jogo são comprados com moedas e gemas ganhas jogando. O app não processa pagamentos com dinheiro real.

4. Anúncios, análises e rastreamento

O jogo não exibe anúncios, não usa ferramentas de análise, não rastreia você entre apps ou sites e não pede permissões de câmera, microfone, localização, contatos ou arquivos.

5. Crianças

O jogo pode ser usado por todas as idades. Como não coletamos dados pessoais, nenhuma informação de crianças é coletada.

6. Seus direitos (LGPD)

Como não guardamos dados pessoais em nossos servidores, não há dados seus para consultar, corrigir ou excluir do nosso lado. Para apagar o progresso, basta limpar os dados do app ou desinstalá-lo. Dúvidas podem ser enviadas para o contato abaixo.

7. Alterações

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização acima.
